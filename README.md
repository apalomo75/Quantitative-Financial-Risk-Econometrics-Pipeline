# Quantitative Financial Risk & Econometrics Pipeline

End-to-end quantitative finance pipeline for financial market analysis, econometric modelling, volatility modelling, tail-risk measurement, derivatives pricing, portfolio optimization and systematic strategy evaluation.

The project is designed as a sequential quantitative research pipeline. Eight Jupyter notebooks implement a complete workflow where each stage builds on outputs generated by earlier stages.

The objective is to build a coherent and reproducible quantitative modelling framework for financial market analysis, integrating econometrics, risk modelling, derivatives analytics, portfolio construction and strategy backtesting within a single structured workflow.

The pipeline implements the full quantitative modelling stack applied to financial markets.

• rolling Sharpe ratio analysis

# Pipeline Architecture

The analysis is implemented as a sequential pipeline of eight notebooks.

| Stage | Notebook | Description |
|------|------|------|
| Data Engineering | N01 | Market data ingestion, cleaning and return construction |
| Econometric Models | N02 | CAPM estimation and econometric diagnostics |
| Time Series | N03 | Unit roots, cointegration and VAR/VECM dynamics |
| Volatility Models | N04 | ARCH, GARCH, GJR-GARCH and volatility forecasting |
| Tail Risk | N05 | VaR, Expected Shortfall and backtesting |
| Derivatives | N06 | Option pricing and Monte Carlo simulations |
| Portfolio | N07 | Portfolio optimization and allocation |
| Strategies | N08 | Strategy construction and backtesting |

Each stage produces structured outputs that are stored and reused by later stages.

**Explicit assumption testing**

Models are evaluated using:

• White test  
• Breusch–Pagan test  
• Durbin–Watson test  
• Breusch–Godfrey test  
• Jarque–Bera test

**Robust inference**

When classical assumptions fail, robust techniques are applied:

• HAC / Newey–West standard errors  
• GARCH-family volatility modelling  
• Student-t innovations for heavy tails

**Financial stylized facts**

The models explicitly account for:

• volatility clustering  
• heavy-tailed return distributions  
• asymmetric volatility responses  
• time-varying correlations
